# Superstore Sales Analysis

## Objective
Analyze the Superstore sales dataset to find which product categories drive the most sales and profit.

## Tools
- Microsoft Excel (PivotTables)

## Dataset
Superstore Sales dataset from Kaggle (9,994 rows, 21 columns).

## Key Findings
- Technology is the top category in both sales ($836K) and profit ($145K).
- Furniture ranks second in sales ($742K) but has by far the lowest profit ($18K).
- Office Supplies has the lowest sales ($719K) but generates strong profit ($122K).

## Next Steps

- Find sub-categories sold at a loss
